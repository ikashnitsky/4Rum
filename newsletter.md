
# February 2026
* {labelled} -- I came across this fantastic suggestion, one can simply specify how the data variables should appear in the plots, and this info will be carried on into the outputs. Think of using this for labelles in Danish that you only need to define once -- <https://www.linkedin.com/posts/cameron-patrick-5b348013b_was-recently-reminded-of-a-cool-r-trick-activity-7423346487193153536-ltiJ>
* {dplyr}, the workhorse of tidy R scripting got a large upgrade with handy new functions and a speed boost to some old ones -- <https://tidyverse.org/blog/2026/02/dplyr-1-2-0>
* {FakeDataR} -- often we can't share the sensitive data. One option is to generate a synthetic dataset that would preserve the main statistical features of the original dataset. Explore -- <https://www.linkedin.com/posts/zobaer-ahmed_rstats-cran-llm-activity-7381524554655039488-TwCf>
* Quarto Wizard -- navigating the endless possibilities of Quarto becomes easier and more straightforward with a VS Code extension -- <https://quarto.org/docs/blog/posts/2025-10-20-quarto-wizard-1-0-0>
* The transition from RStudio to Positron has lots of quirks. Andrew Heiss recently showcased many handy tools that helped him modernize his workflows -- <https://www.linkedin.com/feed/update/urn:li:activity:7429906310151970816>
* R is akin smoking -- if you sometimes think that R is tough and weird, have a look at the comparison people had before tidy era <https://www.johndcook.com/blog/2012/02/29/comparing-r-to-smoking> 
* Hard Fork — not just R, but extremely relevant to anyone trying to stay synced with the development of technology. It's a podcast run by two prominent journalists. For example, the last episode discussed not the future but already the lived reality where AI agents write all of the code previously designed and typed in by humans, and how this changes the landscape of programming. Check the podcast on any streaming platform, including YouTube where sometimes the video is also useful
